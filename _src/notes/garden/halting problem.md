## What is a halting problem?
The halting problem is the question of determining from a description of arbitrary inputs, whether or not a program will finish running, or if it will keep running forever.

The issue with a halting problem wherein it continues on forever has primarily to do with a question of whether or not the components of the program end up in a state of [[recursion]], where there the program continues to re-work the same issue over and over, meaning that the program's output is undecidable.
