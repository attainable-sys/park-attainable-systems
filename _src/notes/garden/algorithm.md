An algorithm is a set of rules that can be guided to create a set of outputs based on those rules, and can be designed to expand those rules with new information in order to continue playing out those rules. Algorithms are traditionally categorized in the computational sense, but are not limited to this setting as algorithmic descriptions are simply procedural ordering of events to evaluate outcomes, the route of which exists within all systems with a set of rules determined by the quality of its components.
