If it was possible to run [[validator]] sets from orbit, there would be no way to actually govern the transactions in the ways that governments want to.

Launching a network so that it operates from orbit could mean that there is no jurisdiction for the network that could regulate its use, and governments would be forced to operate in concurrence WITH the network rather than against it.

Logistically, this network could function across a cluster of cubesats that would operate in orbit and could communicate with one another. Since the interactions are encrypted, any amount of communication between cubesats would be secure, meaning that the network could operate autonomously from any government.

The upshot of this is that if you could actually build out a model that would allow something like this to exist, you could radically change the informational landscape so that the information that is stored in space could be a public good. How it makes money is a completely different question.
