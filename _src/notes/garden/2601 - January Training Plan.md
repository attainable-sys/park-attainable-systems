## RUNNING EXECUTION NOTES

### Long Run Protocol (Saturdays)

- Start 30-45 sec/mi slower than target pace
- First 2 miles should feel absurdly easy
- If HR >150 at any point, slow down
- Bring water + fuel on all runs >60 minutes
- Practice race fueling: 200-300 kcal/hour after 90 minutes

### Benchmark Route (Establish by Jan 18)

- Find 60-90 minute flat course
- Run same route every 2-3 weeks
- Track: Average HR, Average Pace, Efficiency Factor (Pace/HR)
- Calculate aerobic decoupling: ((2nd half HR - 1st half HR) / 1st half HR) × 100
- **Target by March 1:** <5% decoupling
