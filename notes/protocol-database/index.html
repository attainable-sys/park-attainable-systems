protocol database

2000.062 · 2000 blockchain

A protocol database is a location in which all stakeholders who need to learn about a prtocol and the functions therein can go to find information that is most relevant to them. The most important characteristic of this model is that it will result in the stakeholders finding information that is easily referenced for the tasks that they are looking to solve for, as well as centralizing all the information about a protocol and the state that it's in.
