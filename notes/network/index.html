network

2222.050 · 2222 systems

A network is closely related to and exhibits all the characteristics of a system, though a network is simply a map of connections between these components and does not necessarily require any energy flow between these components. A network becomes a system at the point which there are energy flows between components and s degree of interdependence between these components. A network acts as a map of associations between components on the basis of whatever pre-defined set of characteristics; networks that are defined through one set of characteristics may have overlap with another network that defines these components through another set of characteristics.
